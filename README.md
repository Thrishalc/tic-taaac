# Tic Tac Toe

A responsive, dependency-free Tic Tac Toe game. Open `index.html` in a browser to play.

- Play against an unbeatable computer or with a second person.
- The game checks every row, column, and diagonal, highlights the winning squares, and prevents moves after a round ends.
- The scoreboard tracks wins and draws; **New game** clears the board while keeping the score.
